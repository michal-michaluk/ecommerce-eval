# Aggregate

An aggregate is the only object allowed to change business state. It is a package-private class holding an identity, a set of
value objects / policies, and an event buffer. All changes go through command methods on the aggregate; the aggregate never publishes,
never queries, never talks to the outside.

Two main roles exist, but all aggregates follow the same mechanics:

| Role | Recognise it by | Example |
|------|-----------------|---------|
| **Editor** | Represents editable business state with quality and consistency rules without built-in process steps — the class is `{Concept}Editor`, the bare noun is the snapshot | `{Concept}Editor` (an editor aggregate) |
| **Process** | Represents business process with multiple instances, long running (loger then single request), with quality and consistency rules, modeling process steps  | `installation process`, `onboarding process`, `data quality review`) |

Quality and consistency rules:
| Role | Recognise it by | Example |
|------|-----------------|---------|
| **Input validation** | Input value object can validate itself or aggregate method can check based only on the input values, no need to cross validate against internal aggregate state | `new location is given and has coordinates` |
| **Invariant** | Cross validate the input values against internal aggregate state | `new owner is from the same tenant` |
| **Violatoins** | Quality and consistency rules monitored but not blocking processing, some future actions or functions may be blocked | `no location defined` |

Aggregate method roles:
| Role | Recognise it by | Example |
|------|-----------------|---------|
| **Factory** | Creates new instance based on required business information | `start new process`, `initalise new device configuration` |
| **Command** | Modifies state of the instance with protection of quality and consistency rules | `change location`, `assign to new owner`, `finish installation` |
| **Invariant** | Represents quality and consistency rules | `ensure tenant is not changed`, `` |
| **Query** | Projection of the internal state to inmutable form helpfull outside of object | `device configuration snapshot`, `possible actions`, `summary` |
| **Util** | Private other unclassified behaviour to organise code | `check violatoins` |


## How to implement — common to both roles

- Name an **editor** aggregate `{Concept}Editor` and keep it package-private; the bare business noun belongs to its snapshot record (`TariffPlan` is the snapshot, `TariffPlanEditor` is the aggregate), and the command that patches it is `Update{Concept}`. Without this split two people reading two different docs each claim the bare noun and the API ends up returning the wrong type; `aggregate.package-private`
- Give the aggregate an identity field (`deviceId`, `orderId`) as a constructor parameter that is never reassigned; `aggregate.identity`
- Hold changes in a `final List<DomainEvent> events` initialised with `new ArrayList<>()`; the aggregate only appends. Both names are load-bearing: `is.aggregate` recognises an aggregate by a field of type `DomainEvent` named `events`, so renaming either the field or the event type silently switches off **every** `aggregate.*` rule at once — the classifier is the gate for the whole family; `aggregate.events-field`
- Create new instances only through a static factory named as a business sentence, that also records the initial event; `aggregate.factory`
- Provide exactly one all-args constructor — written out explicitly, or generated by `@AllArgsConstructor` — called only from the aggregate's own factory and from the persistence adapter performing rehydration; it must not emit events; `aggregate.all-args-constructor`
- Route every state change through a command method whose name is the business operation (`assignTo`, `updateLocation`, `complete`); `aggregate.command-method`
- Guard each assignment with `!Objects.equals(current, incoming)` so a command that changes nothing emits nothing; `aggregate.change-detection`
- Append an event inside the `if` block, after the assignment, in the same statement group as the change; `aggregate.event-with-change`
- Reject structurally impossible input with `Objects.requireNonNull` at the top of the command, before any guard; `aggregate.require-non-null`
- Let state leave the aggregate only through a query method returning an immutable snapshot record; `aggregate.snapshot-query`
- Name a derived-value query `calculate…` (or `decide…`), never `check…`, `get…` or `is…`: the prefix puts the method inside the policy rule family, so `policy.no-exceptions` and `policy.no-io` apply to it — a calculation answers, it never throws and never reads; `aggregate.calculate-query`
- Keep every aggregate method — command, query, `ensure…`/invariant, factory — inside a statement bound: `function_statements` warning > 7, error > 14. An aggregate that needs more is either doing two commands or holding a rule that belongs in a policy; `aggregate.method-size`
- Keep every field private; identity and the event buffer may be package-visible only because the adapter drains them; `aggregate.private-state`
- Provide no field accessors and no setters — callers read the snapshot, not the aggregate; `aggregate.no-getters`
- Never publish, never call a repository, never read a clock inside the aggregate; `aggregate.no-io`
- Construct the aggregate with `new` only in three places: its own static factory, a persistence adapter rehydrating it, and a test fixture; `aggregate.constructor-callers`

## Model isolation

Everything in the model — aggregate, value objects, policies, domain events, command records — is plain Java. It is compiled
without knowledge of the framework, the database or the transport, which is what makes it testable without Spring and
portable across persistence strategies.

Allowed dependencies of a model class (the complete whitelist):

| Allowed | Why |
|---------|-----|
| its own context package | the model may use its own value objects, events, policies |
| `java..` | records, collections, `java.time`, `Objects`, `Optional`, `BigDecimal` |
| `lombok..` | `@AllArgsConstructor`, `@Builder`, `@Getter` on model types |
| `jakarta.validation..` | bean-validation annotations on command records and value objects |
| `com.fasterxml.jackson..` | `@JsonTypeInfo`, `@JsonSubTypes`, `@JsonIgnore` on persisted events and value objects |

Nothing else. A model class that needs anything from the list below has its logic in the wrong place:

- `model.forbidden-imports` — the import list of a model file contains no `org.`, `io.`, `tools/`, `javax.`, `jakarta.persistence|annotation|transaction|servlet.` or shared-utility package; the import list is the gate, because a dependency shows up there even when it is only a member annotation; `model.forbidden-imports`
- `model.no-tools-dependency` — no type from the shared `tools/` package (JSON mapper, clock, feature store); the caller passes the value in; `model.no-tools-dependency`
- `model.no-framework-annotations` — no `@Service`, `@Component`, `@Repository`, `@Controller`, `@Configuration`, `@Transactional`, `@EventListener`, `@Autowired`, `@Bean`, `@Profile`, `@Scheduled`, `@KafkaListener` on a model type or any of its members; `model.no-framework-annotations`
- `model.no-persistence-types` — no `@Entity`, `@Table`, `@Column`, `JdbcTypeCode`, `@GeneratedValue`, and no `EntityManager`/`JpaRepository`/`CrudRepository` type in the model; `model.no-persistence-types`
- `model.no-model-owner-dependency` — a model type never declares a field of a `*Repository` or `*Service` type; `model.no-model-owner-dependency`
- `model.no-assert` — no `assert` statement anywhere in model code; `model.no-assert`
- `model.no-setters` — no `set*` method on a model type; `model.no-setters`
- `model.no-lombok-data` — no `@Data` on a model type; `model.no-lombok-data`
- `model.no-boxed-boolean-compare` — a boolean is read as itself, never through a literal: no `Boolean.TRUE.equals(x)`, `Boolean.FALSE.equals(active)` or `x == Boolean.TRUE`; a nullable `Boolean` component reads `x != null && x`, a primitive reads `x`; `model.no-boxed-boolean-compare`
- `model.no-cross-context-imports` — no import of another context's package; cross-context input arrives as a declared contract record or through a port. *Reviewed, not encoded*: the declared shared kernel would have to be listed per context, so this one stays a review rule; `model.no-cross-context-imports`

Application forms a model *file* as one that declares no adapter or service type and carries no framework annotation on its
types (`*Controller`, `*Repository`, `*Projection`, `*Entity`, `*Service`, `*Listener`, `*Client`, `*Integration`, `*Fixture`,
`*Assert`, `*Test`, `*Description`, `*Mapper`, `*Runner`, `*Configuration`, `*Mediator`). Every rule above is evaluated there.

### Enforcement

The rules live in `.agents/sqt.yaml` and are evaluated by `sqt check src` — an `error` severity exits `5`, so the gate fails
on the first deviation:

```sh
sqt check src                 # gate
sqt report src --jsonl        # same facts, never fails
sqt explain src/main/java/devices/configuration/device/DeviceConfigurationEditor.java
```

**Encoded** (`sqt`, `error`): `aggregate.package-private`, `aggregate.all-args-constructor`, `aggregate.private-state`,
`aggregate.no-getters`, `aggregate.no-io`, `aggregate.no-transaction`, `aggregate.identity`, `aggregate.factory`,
`aggregate.snapshot-query`, `aggregate.calculate-query`; `aggregate.events-field` is the classifier input that makes an
aggregate recognisable, and `aggregate.constructor-callers` is a dependency rule over the code graph. `error` severity exits
`5`, so the gate fails on the first deviation.

**Encoded as `warning`** (heuristic, reported but never gates): `aggregate.change-detection`, `aggregate.event-with-change`.

**Measured** (`scope:` in `.agents/sqt.yaml`, never gates below `error`): `aggregate.method-size` — `function_statements` warning > 7,
error > 14 on every method inside an aggregate. The metric flattens lambdas written in the method and counts each switch-expression arm, so read a high number before changing the code.

**Enforced by ArchUnit, not `sqt`**: `aggregate.constructor-callers` also backs the access isolation in
`ArchitectureOfDeviceContextTest`.

The corpus is clean: `sqt check src` reports `0 error`; the only domain-model findings are four `vo.factory` hints.

**Review-only**: `aggregate.command-method`, `aggregate.consistency-boundary`, `aggregate.no-whole-state-writer`,
`aggregate.require-non-null` — the last one cannot hold, because `updateLocation(null)` legitimately clears the location.

## Example — editor role

The editor keeps its role; what is added is the `ensure…` idiom, so one command shows rejection and reporting side by side. An
editor with guards is still an editor — it gains no lifecycle and no terminal state.

```java
@AllArgsConstructor
class DeviceConfigurationEditor {

    final String deviceId;
    final List<DomainEvent> events;
    private Ownership ownership;
    private Location location;
    private OpeningHours openingHours;
    private Settings settings;

    static DeviceConfigurationEditor newDevice(String deviceId) {
        return new DeviceConfigurationEditor(
                deviceId,
                new ArrayList<>(),
                Ownership.unowned(),
                null,
                OpeningHours.alwaysOpened(),
                Settings.defaultSettings()
        );
    }

    void assignTo(Ownership ownership) {
        Objects.requireNonNull(ownership);
        ensureOwnershipIsComplete(ownership);

        if (!Objects.equals(this.ownership, ownership)) {
            this.ownership = ownership;
            events.add(new OwnershipUpdated(deviceId, ownership));

            if (ownership.isUnowned()) {
                resetToDefaults();
            }
        }
    }

    void updateLocation(Location location) {
        if (!Objects.equals(this.location, location)) {
            this.location = location;
            events.add(new LocationUpdated(deviceId, location));
        }
    }

    void updateSettings(Settings patch) {
        Objects.requireNonNull(patch);
        Settings merged = this.settings.merge(patch);

        if (!Objects.equals(this.settings, merged)) {
            ensureSettingsAreAddressable(merged);
            this.settings = merged;
            events.add(new SettingsUpdated(deviceId, merged));
        }
    }

    void updateOpeningHours(OpeningHours openingHours) {
        Objects.requireNonNull(openingHours);
        if (!Objects.equals(this.openingHours, openingHours)) {
            this.openingHours = openingHours;
            events.add(new OpeningHoursUpdated(deviceId, openingHours));
        }
    }

    private void resetToDefaults() {
        updateLocation(null);
        updateOpeningHours(OpeningHours.alwaysOpened());
        updateSettings(Settings.defaultSettings());
    }

    private void ensureOwnershipIsComplete(Ownership ownership) {
        if (!ownership.isOwned() && !ownership.isUnowned()) {
            throw new IllegalArgumentException("ownership must be complete or absent");
        }
    }

    private void ensureSettingsAreAddressable(Settings merged) {
        if (merged.isShowOnMap() && location == null) {
            throw new IllegalStateException("showOnMap requires a location");
        }
        if (merged.isShowOnMap() && !merged.isPublicAccess()) {
            throw new IllegalStateException("showOnMap requires publicAccess");
        }
    }

    private Violations calculateViolations() {
        return Violations.builder()
                .operatorNotAssigned(ownership.operator() == null)
                .providerNotAssigned(ownership.provider() == null)
                .locationMissing(location == null)
                .showOnMapButMissingLocation(settings.isShowOnMap() && location == null)
                .showOnMapButNoPublicAccess(settings.isShowOnMap() && !settings.isPublicAccess())
                .build();
    }

    DeviceConfiguration toDeviceConfiguration() {
        Violations violations = calculateViolations();
        Visibility visibility = Visibility.calculateVisibility(
                violations.isValid() && settings.isPublicAccess(),
                settings.isShowOnMap()
        );
        return new DeviceConfiguration(
                deviceId, ownership, location, openingHours, settings, violations, visibility);
    }
}
```

The example carries, in one command, the whole editor contract: `Objects.requireNonNull` → `ensure…` → merge of value
objects → change detection → event → derived snapshot.

Deliberate additions over the plain editor:

- `ensureOwnershipIsComplete` / `ensureSettingsAreAddressable` are added — the plain editor would
  store a contradictory request;
- `resetToDefaults()` is shown `private`; in the source it is package-private;
- `@AllArgsConstructor` is shown on the class; the source annotates it identically — without it the six-argument
  constructor call in the factory has nothing to bind to;
- the event payload uses the merged value (`new SettingsUpdated(deviceId, merged)`), while the source passes the stored
  field (`new SettingsUpdated(deviceId, this.settings)`) — the merged instance is the correct payload, since it is the value
  that the event is compared against.

### Rules specific to the editor role

- Reject only the requests that are *contradictory in themselves* with an `ensure…` method throwing `IllegalArgumentException`/`IllegalStateException`; `editor.ensure-rejects-contradiction`
- Report a merely *incomplete* configuration through `Violations` flags and never by throwing; `policy.no-exceptions`
- Put one boolean flag per business condition in `Violations` and a single `isValid()` that conjoins them; `editor.violation-flags`
- Emit an event for every change the command actually performs — one command may emit several events, a no-op emits none; `editor.event-per-change`
- Merge inbound value objects before comparing, so `null` components never overwrite stored values; `editor.merge-before-compare`
- Keep the inbound partial-update payload outside the aggregate and let it apply itself (`Update{Concept}.apply({Concept}Editor)`), so the aggregate exposes commands only; `editor.patch-payload-applies-itself`
- Reset dependent state inside the command that invalidates it (`ownership.isUnowned()` ⇒ `resetToDefaults()`), not in the caller; `editor.cascade-reset`

## Example — process role

```java
@AllArgsConstructor
class InstallationProcess {

    final List<DomainEvent> events;
    final String orderId;
    String deviceId;
    private Ownership ownership;
    private BootNotification boot;
    private Location location;
    private boolean bootConfirmation;
    private boolean active;

    static InstallationProcess startInstallationProcessFor(WorkOrder order) {
        Objects.requireNonNull(order.orderId());
        assert order.ownership().isOwned();
        var process = new InstallationProcess(
                new ArrayList<>(), order.orderId(), null, order.ownership(),
                null, null, false, true);
        process.events.add(new InstallationStarted(order.orderId(), order));
        return process;
    }

    void assignDevice(String deviceId) {
        Objects.requireNonNull(deviceId);

        ensureProcessIsActive();
        if (!Objects.equals(this.deviceId, deviceId)) {
            this.deviceId = deviceId;
            boot = null;
            bootConfirmation = false;
            events.add(new DeviceAssigned(orderId, deviceId));
        }
    }

    void assignLocation(Location location) {
        Objects.requireNonNull(location);

        ensureProcessIsActive();
        this.location = location;
        events.add(new LocationPredefined(orderId, deviceId, location));
    }

    void handleBootNotification(BootNotification boot) {
        Objects.requireNonNull(boot);

        if (!active) return;
        boolean bootConfirmed = this.bootConfirmation && Objects.equals(this.boot, boot);
        this.boot = boot;
        this.bootConfirmation = bootConfirmed;
        events.add(new BootNotificationProcessed(orderId, deviceId, boot, bootConfirmed));
    }

    void confirmBootData() {
        if (bootConfirmation) return;
        this.bootConfirmation = true;
        events.add(new BootNotificationProcessed(orderId, deviceId, boot, bootConfirmation));
    }

    CompletionResult complete() {
        ensureProcessIsActive();
        boolean locationIsDefined = location != null;
        boolean bootIsConfirmed = boot != null && this.bootConfirmation;
        if (locationIsDefined && bootIsConfirmed) {
            active = false;
            events.add(new InstallationCompleted(orderId, deviceId));
        }
        return CompletionResult.builder()
                .locationIsDefined(locationIsDefined)
                .bootIsConfirmed(bootIsConfirmed)
                .location(location)
                .ownership(ownership)
                .build();
    }

    InstallationProcessState asState() {
        return new InstallationProcessState(orderId, deviceId, state());
    }

    private State state() {
        if (!active) return State.COMPLETED;
        if (boot != null) return State.BOOTED;
        if (deviceId != null) return State.DEVICE_ASSIGNED;
        return State.PENDING;
    }

    private void ensureProcessIsActive() {
        if (!active) throw new IllegalStateException();
    }
}
```

`assignLocation` is reproduced exactly as it exists: it has no change detection and appends an event on every call. Do not
copy that part — an idempotent command guards with `!Objects.equals(this.location, location)`, like `assignDevice` does.

The class is quoted with `@AllArgsConstructor` from the source; no other deviation.

The factory guards its input with `assert order.ownership().isOwned();`, reproduced as it exists. Assertions are not enabled
in this build, so the guard does not fire. Write the enforced version instead:

```java
if (!order.ownership().isOwned()) {
    throw new IllegalArgumentException("installation must start from an owned work order");
}
```

### Rules specific to the process role

- Start every command that changes state with `ensure<Precondition>()` that throws when the process is no longer active; `process.guard-method`
- Make the terminal transition a command that returns an outcome record (what was satisfied, what was missing) instead of `void`; `process.outcome-record`
- Derive the published state enum in a private method from field presence, and never store it as a mutable field; `process.derived-state`
- Let a command that records an external fact stay unguarded by the terminal check and return early instead of throwing — a fact that happened cannot be negated; `process.event-handler-no-guard`
- Reset dependent fields inside the command that replaces their subject (`assignDevice` clears `boot`/`bootConfirmation`); `process.cascade-reset`
- Prefer computing the transition condition locally and emitting the event only inside that branch; `process.conditional-transition`

## What to avoid / NOGO

- Do not let a controller, a service or a projection construct the aggregate with `new`; new instances come from the static factory, and the only other constructor caller is the persistence adapter performing rehydration; `aggregate.constructor-callers`
- Do not construct the aggregate with `new` inside a test method — put the construction in the context's `*Fixture`, so one place owns the valid starting state; `aggregate.constructor-callers`
- Do not import `org.springframework..`, `jakarta.persistence..`, the shared `tools/` package or a sibling context into a model class — move the behaviour to the service or the adapter; `model.forbidden-imports`
- Do not publish events from the aggregate; the repository drains `events` and publishes — the aggregate must not know `ApplicationEventPublisher`; `aggregate.no-io`
- Do not emit an event before mutating the state, or outside the change-detection branch; `aggregate.event-with-change`
- Do not annotate a command with `@Transactional`; transaction boundaries belong to the service; `aggregate.no-transaction`
- Do not throw for an *incomplete* editor configuration — an incomplete configuration is a valid stored state, reported through `Violations`; `policy.no-exceptions`
- Do not accept a contradictory request by storing it and reporting it later; reject it with `ensure…` and leave the state unchanged; `editor.ensure-rejects-contradiction`
- Do not accumulate lifecycle checks in one `isValid()` boolean; each transition gets its own `ensure…` method naming the precondition; `process.guard-method`
- Do not expose the event list, the identity mutably, or a `save()`/`update()`-style method that takes the whole new state; `aggregate.no-whole-state-writer`
- Do not guard a precondition with `assert` — assertions are disabled unless the build enables them, so the guard never fires; `model.no-assert`
- Do not read a flag through a literal — `if (ownership.isUnowned())`, not `Boolean.TRUE.equals(ownership.isUnowned())`, and `boolean bootIsConfirmed = boot != null && this.bootConfirmation` for a nullable source; the query method already returns the answer; `model.no-boxed-boolean-compare`
- Do not create one aggregate per table or per read model — the aggregate protects a consistency boundary, read models live in projections; `aggregate.consistency-boundary`
